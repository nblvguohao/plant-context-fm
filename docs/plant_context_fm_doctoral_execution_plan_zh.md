# PlantContext-FM 博士研究项目执行计划

版本：v1.0  
日期：2026-07-29  
建议周期：36 个月  
项目性质：计算植物生态学 × 数量遗传学 × 多模态机器学习

## 1. 项目定位

### 1.1 建议总题目

**面向跨环境泛化的植物上下文基础模型：从群落生态语法到基因型–环境–表型互作**

英文工作题目：

**PlantContext-FM: Structured Foundation Models for Plant Communities and Genotype-by-Environment Phenotypes**

> **术语说明。** 本计划使用“foundation model / 基础模型”一词时，指在植物领域特定数据上训练的结构化上下文表示框架，而非从零训练超大通用 DNA 模型。第一阶段不预训练大规模通用 DNA foundation model（见 TDD §1.2），预训练收益将通过对照实验在低样本和 OOD 条件下评估，而不是默认假设。

### 1.2 两句话研究陈述

现有植物群落模型和作物 G×E 模型分别处理群落共现与育种表型，但都面临结构表示不充分、跨区域/跨年份泛化弱以及模型归因不能等同于生物关联的问题。

本项目以“植物响应取决于上下文”为共同原理，构建染色体/LD、物候环境和群落组成的结构化 token、自监督预训练及可校准推断框架，分别在植物群落和多环境作物试验中验证。

**面向非专业读者的解释。** 无论是森林中的一个样方，还是农田里的一次品种试验，植物的响应都取决于它所处的“上下文”——周围有哪些物种、气候和土壤如何、基因型背景是什么。本项目试图把这种上下文变成可学习的“语法”：用染色体上的相邻关系、物候阶段的连续性和物种分类的层级来组织数据，让模型在未见过的环境或年份中也能稳健预测，并且明确区分“模型能预测”与“这就是生物学原因”。

### 1.3 核心示意图计划

为帮助跨学科读者理解统一原理，第一章/Paper 2 将包含一张核心示意图（Figure 1），展示：

- 左侧：一个植物群落样方（物种、丰度、样方环境）通过 Community Tokenizer 生成结构化 token；
- 右侧：一次 G×E 田间试验（SNP/LD block、物候天气、土壤管理）通过 Genotype Tokenizer 和 Environment Tokenizer 生成结构化 token；
- 中间：Shared Environment Encoder 作为两者之间的桥接；
- 下方：统一的评估协议（OOD 划分、校准、不确定性）。

该图将突出“植物响应取决于上下文”这一共同原理，而非技术细节。

## 2. 两部分能否组成博士大论文

可以，但不能只是“复现 Pl@ntBERT”和“运行 SRG-GxE”两篇互不相干的工作。博士论文需要一个共同的方法学问题和至少一个真实的桥接实验。

### 2.1 共同科学问题

两部分都研究：

1. 什么是植物系统中可学习的“上下文语法”；
2. 如何用结构化自监督学习减少标签依赖；
3. 如何泛化到未见区域、环境、年份或基因型；
4. 如何区分预测相关性、统计关联与因果解释；
5. 如何量化模型在分布外条件下的不确定性。

### 2.2 两部分的映射

| 生态群落部分 | G–P–E 部分 | 共同抽象 |
|---|---|---|
| 物种 token | SNP/LD block/基因 token | 生物实体 token |
| 丰度/盖度排序 | 染色体坐标和 LD 结构 | 结构先验 |
| 样方环境 | 田间天气、土壤、管理 | 环境上下文 |
| 缺失物种预测 | 遮盖单倍型/环境阶段恢复 | 自监督学习 |
| 群落/生境分类 | 表型、稳定性和环境敏感度预测 | 下游任务 |
| 跨区域外推 | 未见环境/年份/基因型外推 | 分布外泛化 |
| 物种贡献解释 | 环境依赖 SNP 效应 | 可解释性与推断 |

### 2.3 必须设置的桥接章节

建议增加一个共享方法章节，避免两部分被评审认为拼接：

**结构化植物上下文建模与跨尺度迁移**

桥接内容至少实现两个：

- 同一个物候/气候环境编码器同时用于群落和作物数据；
- 同一套结构化遮盖原则分别作用于物种群落和 LD/物候 token；
- 同一套 OOD、校准和不确定性评估协议；
- 从群落数据预训练环境表示，再测试其是否改善低样本 G×E 预测；
- 对“注意力/归因不等于生物关联”给出统一的验证框架。

如果桥接实验失败，也可以形成有价值的边界研究：说明生态环境表示何时不能迁移到农田系统，并诊断原因。

#### 桥接实验预注册决策规则

为区分“迁移成功”“域差距失败”与“模型容量失败”，H5 的验证需预先规定：

- **正向证据**：在至少两个 OOD 或低样本任务上，使用群落预训练环境编码器（冻结或部分微调）的 G×E 模型一致优于同架构随机初始化（配对 bootstrap 95% CI 不跨 0；或按 §9 的统计功效标准）。
- **域差距失败**：G×E 任务上微调后的群落编码器不优于领域内重新训练；诊断显示自然群落与农田环境在气候/物候分布、土壤变量或管理强度上存在不可覆盖的偏移。
- **容量失败**：领域分布重叠度足够但迁移仍失败；消融显示增加容量、更多微调数据或不同融合方式可消除差距。
- **报告义务**：三种结果均视为有效贡献；失败时需在 Discussion 中明确失败模式和迁移边界。

### 2.4 与先前工作的关系

本项目不是孤立提出一套全新框架，而是在以下几条已有线索上增加更严格的数据契约、防泄漏协议和可校准推断：

1. **统计 G×E 传统。** GBLUP、反应规范（reaction norm）、因子分析 / MegaLMM 是本项目的强基线和可解释主干。本项目的增量不在于替代它们，而在于用深度残差模型检验是否存在可重复的非线性 G×E 信号，并在相同外层划分下与它们公平比较。

2. **作物 G×E 深度学习。** 近年已有若干深度 / 图神经网络用于 G×E 预测的研究。本项目的约束更严格：必须在 leave-environment、forward-year、leave-genotype、leave-GE 划分上评估；必须报告不确定性校准；必须将预测归因与统计关联分离；必须使用 SRG-GxE 审计结果作为方法学教训（见 `docs/srg_gxe_audit_2026-07-29.md`）。

3. **基因组基础模型。** PlantCaduceus、Evo2 等预训练 DNA 模型是 GenotypeTokenizer 的候选编码器路径之一，但本项目不假设它们必然优于从头学习的 SNP/LD block 表示。TDD §6.4 将它们作为可选路径评估，而非默认依赖。

4. **生态基础模型与 Pl@ntBERT。** Paper 1 以严格复现和边界审计为起点，Paper 2 以结构化 token 化（taxonomy-aware、abundance-aware、environment-aware）和 OOD 评估为增量贡献。目标不是“另一个 Pl@ntBERT”，而是明确回答：在哪些缺失机制、稀有物种和跨区域条件下群落“语法”成立或失效。

5. **SRG-GxE。** 作为本项目的直接前身代码库（`external/srg_gxe`），SRG-GxE 提供了关于 token 顺序效应、weather window 截断、统计功效和验证脚本的重要教训。Paper 3 将在此基础上做修正、严格化和独立验证，而不是简单沿用其 headline 结论。

## 3. 博士论文建议结构

### 第一章：绪论与统一问题

- 植物上下文依赖性；
- 群落共现、表型可塑性和 G×E 的关系；
- 结构化上下文表示、自监督学习、反应规范与关联分析；
- 研究假设和评价标准；
- **明确本论文的主要 register：以“结构化植物上下文建模”方法学创新为主线，以群落和 G×E 作为两个验证领域。**

### 第二章 / Paper 1：Pl@ntBERT 的严格复现与边界审计

目标：

- 复现缺失物种预测和生境分类；
- 建立跨区域、跨时间、稀有物种和真实缺失机制评估；
- 检验随机 mask、丰度顺序和伪标签可能带来的偏差；
- 形成可复用的群落表示基线。

预期贡献：

- 一个更严格的生态基础模型评测协议，可为生物多样性信息学和生态监测领域的模型可信度评估提供参考；
- 群落“语法”在哪些条件下成立或失效的证据。

### 第三章 / Paper 2：结构化植物上下文自监督模型

目标：

- 构建 taxonomy-aware、abundance-aware、environment-aware token；
- 比较随机 mask、整类群 mask、连续环境 mask 和结构化 mask；
- 加入环境表示、不确定性和 OOD 检测；
- 提供群落与 G×E 共用的环境编码器。

预期贡献：

- 论文的核心方法学创新；
- 两个研究部分的真正连接点。

### 第四章 / Paper 3：物候对齐的 G×E 预测

目标：

- 以 G2F 为主数据；
- 建立并评估 GBLUP、reaction norm、factor-analytic/MegaLMM 强基线；
- 将 SNP 表示为染色体内 LD/基因块；
- 将天气表示为物候阶段胁迫 token；
- 用深度模型学习混合模型未解释的非线性残差；
- 严格测试未见环境、年份、基因型和 G–E 组合；
- **预先评估统计功效，确保种子数或交叉验证设计足以分辨本领域典型模型差距（见 SRG-GxE 审计中 n=3 种子 MDE 不足的问题）。**

预期贡献：

- 一个防泄漏、可校准的 G×E 多模态预测框架；
- 对 SRG-GxE 残差学习假设的严格验证与修正，明确深度残差在何种条件下优于或不优于强统计基线。

### 第五章 / Paper 4：环境依赖位点关联与外部验证

目标：

- 建立环境依赖 SNP 效应函数；
- 使用亲缘、群体结构、测试者和空间设计校正；
- **显式分离并报告站点历史、管理实践和空间设计带来的共线性，避免将它们误作环境依赖遗传效应；**
- 通过置换、bootstrap、FDR 和留出年份验证候选位点；
- 使用 CIMMYT/FIP1/TERRA-REF 中至少一个独立数据集验证方法；
- 将候选区域映射至基因、QTL 和胁迫通路。

预期贡献：

- 从“预测解释”走向“统计关联”的方法；
- 具有生物学可信度的环境特异候选基因。

### 第六章：统一讨论

- 群落语法与基因组/环境语法的共同性和边界；
- 自监督表示能否跨生态—育种尺度迁移；
- 预测、关联和因果之间的界线；
- 对气候适应型育种和生态监测的意义。

## 4. 核心研究假设

### H1：结构假设

保留类群、染色体/LD 和物候邻接关系的 token 化，比随机或仅按统计量排序的 token 化具有更好的 OOD 泛化。

### H2：自监督假设

结构化遮盖预训练主要在标签较少、未见环境和未见年份条件下产生收益，而不一定提高随机划分结果。

### H3：统计—深度互补假设

反应规范/混合模型能够可靠建模主效应和线性交互，深度残差模型只在存在可重复非线性 G×E 时提供额外收益。

### H4：关联假设

经过亲缘校正、经验零分布和跨年份重复验证的环境依赖效应，预期比注意力或单次梯度归因更稳定、更可能接近真实 G×E 位点。

### H5：跨尺度假设（待检验）

环境编码器可能比基因型或物种编码器具有更强的跨任务迁移性；群落到作物的迁移应优先迁移气候/环境表示，而不是直接迁移物种或 SNP token。该假设是否成立将通过 §2.3 的预注册桥接实验评估；若失败，将转为边界研究并诊断原因。

## 5. 数据策略

### 5.1 核心数据

- 群落：优先使用 sPlotOpen/公开植被样方建立可复现实验；EVA 仅在获得授权后作为扩展。**当前状态（2026-07-30）：sPlotOpen 数据尚未完成下载与适配；若 P0 结束（M1）前无法获得合法可用的公开群落数据，将启动备选公开数据集（如 GBIF 衍生样方、FIA 等）并调整 Paper 1 范围。**
- 玉米：G2F 2014–2023 表型、天气、土壤、管理和 437k SNP。
- 外部验证：CIMMYT 小麦 3,731 品系 × 9,045 SNP × 4 环境。

### 5.2 可选扩展

- FIP 1.0：冬小麦多年度、高频环境和影像表型；
- TERRA-REF：高粱基因组和高通量时序表型；
- ERA5-Land、NASA POWER、Daymet：统一环境数据；
- SoilGrids/SSURGO：土壤；
- MaizeGDB、Gramene、Ensembl Plants：基因和 QTL 注释。

### 5.3 数据冻结原则

每篇论文必须记录：

- 数据集 DOI/版本和下载日期；
- 样本排除规则；
- 参考基因组版本；
- 原始到分析表的哈希和处理日志；
- 外层划分文件；
- 训练折拟合的插补、标准化和特征选择状态。

### W3–W4：数据契约与划分

- 实现 phenotype/genotype/environment/weather/soil 表；
- 建立 leave-environment、forward-year、leave-genotype、leave-GE 划分；
- 写完数据契约、泄漏测试和最小合成数据；

### W5–W6：统计基线

- 完成 environment mean、Ridge/GBLUP、reaction norm；

- 建立 RMSE、Pearson、Spearman、Top-k gain、校准指标；
- 输出逐环境误差图谱。

### W7–W8：SRG-GxE 审计性复现

- 修正 SNP 坐标排序和染色体边界；
- 复现直接表型与残差两种模式；
- 完成 3 个随机种子，并评估统计功效是否足以分辨典型模型差距；
- 比较 LightGBM 和统计基线；
- 记录 SRG-GxE 的“语法”效应空转、weather window 截断和验证脚本问题作为方法学教训；

- 实现 LD-block mask、连续物候阶段 mask；
- 增加固定目标或 EMA teacher；

- 检查表示塌缩和预训练增益。

### W11–W12：决策门

- 汇总所有 paired bootstrap 置信区间；
- 判断残差路线、直接预测路线或负结果路线；
- 冻结博士课题 v1 研究问题；
- 输出首篇论文的图表草案和实验清单。

完成标准：所有深度模型必须在相同外层划分和相同数据上对比 GBLUP/RN/FA/MegaLMM。

### WP3：结构化自监督模型

完成标准：具备群落、基因型和环境三种 tokenizer；mask 行为可测试；低样本曲线完整。

### WP4：G×E 多模态预测

完成标准：四类外推划分、三至五个种子、配对置信区间和不确定性校准。

### WP5：关联推断

完成标准：模拟校准、经验零分布、FDR、稳定性、跨年份重复和基因注释形成完整证据链。

### WP6：开放科学与论文

完成标准：配置、日志、模型卡、数据卡、可复现实验清单和论文图表一一对应。

## 9. 成功指标

### 方法成功

- 新方法相对最佳调参基线的改善，在至少两个主要 OOD 划分上方向一致；
- 三个以上随机种子的配对 bootstrap 95% CI 不跨 0，**且该判断的统计功效需预先评估（参考 SRG-GxE 审计：n=3 种子在 leave_environment 上的 MDE 约为 1.94 RMSE，远超典型模型差距 0.11–0.34）；**
- 低样本条件下的自监督收益明显高于全数据条件；
- 预测区间在不同环境类型下保持可接受覆盖率。

### 关联成功

- 模拟数据上的经验 FDR 不高于目标水平；
- 候选位点在 bootstrap 中达到预设稳定性；
- 至少一组环境依赖效应能在留出年份或独立数据集中重复；
- 注意力、归因和统计关联结果明确分开报告。

### 博士课题成功

- 至少三篇相互关联的主体论文；
- 至少一篇是共享方法/桥接论文；
- 至少一个公开可复现基准或软件包；
- 论文主线不依赖单一模型超过基线这一结果。

## 10. 失败时的备选论文路线

| 失败情形 | 可转化的问题 |
|---|---|
| Pl@ntBERT OOD 泛化弱 | 植物群落基础模型的分布偏移与伪标签边界 |
| 自监督预训练不增益 | 何时基因型/群落预训练不优于强统计基线 |
| 深度残差不优于 RN/MegaLMM | 复杂 G×E 模型的简单性审计 |
| 跨作物 SNP 迁移失败 | 位置不对齐条件下基因组表示不可迁移的机制 |
| 环境表示迁移失败 | 自然生态与农田管理环境的域差异 |
| 归因位点不稳定 | 深度模型解释与多环境 GWAS 的系统比较 |

这些不是项目失败，而是需要在研究开始前预注册的可发表边界问题。

## 11. 资源预算

### MVP

- 1 张 24–48 GB GPU；
- 64–128 GB 内存；
- 2 TB 可用存储；
- CPU 节点用于 VCF、混合模型和置换；
- 不下载全部 FIP/TERRA-REF 原始影像。

### 完整版本

- 2–4 张 80 GB GPU，用于大规模群落预训练和多种子实验；
- 256 GB 内存；
- 5–10 TB 存储；
- 可抢占计算队列用于 bootstrap、置换和外部验证。

优先级是数据质量、统计基线和严格划分；算力扩展仅在 12 周可行性门通过后进行。

## 12. 立即开始条件

满足以下条件即可启动：

1. 明确博士课题以“植物上下文模型与跨环境泛化”为总主线；

3. 将 FIP1 设为可选扩展，而不是关键路径；

5. 先完成 12 周 MVP，再决定是否进行大规模预训练；
6. **在 M1 结束前确认群落数据可合法获取，否则立即启动备选数据方案。**
